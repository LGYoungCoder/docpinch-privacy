# DocPinch Privacy

Public privacy policy and support surface for **DocPinch: Photo to PDF**.

- Live policy: <https://lgyoungcoder.github.io/docpinch-privacy/>
- Support and privacy questions: <https://github.com/LGYoungCoder/docpinch-privacy/issues>

The page is deliberately static: no analytics, cookies, forms, remote fonts, or JavaScript.

## Publishing

GitHub Pages serves the `main` branch from the repository root. Changes to the policy should be committed before the corresponding app release and reviewed against the final Android manifest, dependencies, Google Play Data Safety form, and in-app privacy copy.
